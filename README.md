# هوش‌یار (Hoshemasnooi)

**هوش‌یار** یک اپلیکیشن اندروید فارسی (راست‌به‌چپ) است که مطالب مرتبط با **هوش مصنوعی** را
از منابع عمومی گردآوری می‌کند، آن‌ها را **دسته‌بندی موضوعی** می‌کند و به **زبان فارسی**
برمی‌گرداند.

> نسخه ۱٫۰٫۰ — سازگار با اندروید ۵٫۰ (API 21) و بالاتر

---

## قابلیت‌ها

- 🗂️ **دسته‌بندی خودکار** مطالب در ۱۱ دسته: اخبار، مدل‌های زبانی، تصویر و ویدیو،
  کدنویسی، پژوهش، ابزارها، کسب‌وکار، اخلاق و ایمنی، قوانین، آموزش و سایر.
- 🌍 **ترجمه خودکار به فارسی** با چند سرویس عمومی و واژه‌نامه تخصصی هوش مصنوعی (آفلاین).
- 🔎 **جست‌وجو** و **فیلتر دسته‌بندی**.
- 📰 **سه منبع داده**:
  1. خوراک‌های RSS مبتنی بر Nitter برای حساب‌های تخصصی هوش مصنوعی.
  2. یک فایل JSON آنلاین قابل تنظیم (مثلاً میزبانی‌شده روی GitHub).
  3. مجموعه‌داده از پیش ترجمه‌شده همراه برنامه (برای استفاده بدون اینترنت).
- 💾 **ذخیره‌سازی محلی** تا مطالب بدون اتصال نیز در دسترس باشند.
- 📤 اشتراک‌گذاری، کپی متن و بازکردن مطلب اصلی.
- 🌙 پشتیبانی از حالت روشن/تاریک.

## دریافت برنامه

فایل APK از بخش **Releases** همین مخزن قابل دریافت است. همچنین در هر بار
اجرای گردش‌کار، APK در بخش **Artifacts** نیز ساخته می‌شود.

## ساخت از منبع

نیازمندی‌ها: JDK 17، Android SDK (platform 34 و build-tools 34).

```bash
./gradlew assembleDebug     # نسخه آزمایشی
./gradlew assembleRelease   # نسخه انتشار
```

خروجی در مسیر `app/build/outputs/apk/` ساخته می‌شود.

## امضای نسخه انتشار (اختیاری)

برای امضای نسخه انتشار، متغیرهای محیطی زیر را تنظیم کنید:

| متغیر | توضیح |
| --- | --- |
| `KEYSTORE_PATH` | مسیر فایل کی‌استور (`.jks`) |
| `KEYSTORE_PASSWORD` | گذرواژه کی‌استور |
| `KEY_ALIAS` | نام کلید (پیش‌فرض `hoshemasnooi`) |
| `KEY_PASSWORD` | گذرواژه کلید |

ساخت یک کی‌استور نمونه:

```bash
keytool -genkeypair -v -keystore release.jks -keyalg RSA -keysize 2048 \
  -validity 10000 -alias hoshemasnooi
```

اگر این متغیرها تنظیم نشوند، نسخه انتشار با کلید پیش‌فرض اشکال‌زدایی امضا می‌شود
(برای انتشار در بازار اندروید، حتماً از کی‌استور اختصاصی خود استفاده کنید).

## ساخت خودکار با GitHub Actions

گردش‌کار `.github/workflows/build.yml` به‌صورت خودکار APK را می‌سازد. برای امضای
نسخه انتشار، این **Secrets** را در تنظیمات مخزن اضافه کنید:

- `KEYSTORE_BASE64` — خروجی `base64 -w0 release.jks`
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`

افزودن برچسب نسخه (مثلاً `v1.0.0`) باعث پیوست‌شدن APK به Release می‌شود.

## ساختار پروژه

```
app/src/main/
├── assets/            مجموعه‌داده همراه و واژه‌نامه
│   ├── seed_feed.json
│   └── glossary.json
├── java/ir/hoshemasnooi/app/
│   ├── data/          دریافت، دسته‌بندی و ترجمه
│   ├── model/         مدل‌های داده
│   ├── ui/            رابط کاربری Compose
│   ├── util/          ابزارهای HTTP
│   └── viewmodel/     مدیریت وضعیت
└── res/               منابع (فارسی، آیکون‌ها، پوسته)
```
